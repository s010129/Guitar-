雙機吉他

手機當左手按和弦，iPad 當右手刷弦發聲。
兩台裝置透過 Wi-Fi 點對點連線。

🤚
iPad

右手・刷弦

上下滑過琴弦刷弦、點弦彈單音、點琴身其他地方會有敲擊聲、按住琴橋可以悶音。可切換木吉他、古典、電吉他、破音、貝斯、烏克麗麗、12 弦。聲音從這台出來。
✋
手機

左手・指板

多指同時按格子、往旁邊的弦拖可以橫按、左右滑是滑音；也可以切到「和弦」模式一鍵按和弦。

怎麼開始

  1. iPad 和手機連同一個 Wi-Fi（沒有 Wi-Fi 的話，讓 iPad 連手機的個人熱點）。
  2. iPad 打開「右手」，點「開始」，畫面左上角會出現 4 位數房號。
  3. 手機用相機掃 iPad 上「📱 連手機」的 QR Code，或在這裡輸入房號：
  4. 兩邊都亮綠燈就可以彈了。手機建議橫放，放在 iPad 左邊，看起來就像一把吉他。

只有 iPad 也能玩：右手頁面下方有「和弦列」，點和弦再刷弦即可。

連線方式評估：為什麼選網路（WebRTC）

方式網頁可行？原因
藍牙不可行iPhone / iPad 上所有瀏覽器（Safari、Chrome）都不支援 Web Bluetooth；而且網頁只能當「主控端」，兩台瀏覽器無法互相配對。
有線（USB / Lightning）不可行iOS 不支援 WebUSB / Web Serial，網頁拿不到線材的資料通道。
網路 WebRTC✔ 採用瀏覽器內建的點對點資料通道，同一個 Wi-Fi 下延遲約 5–20 ms，iOS Safari 完整支援。只有一開始配對時需要連網（PeerJS 免費配對伺服器），之後資料直接在兩台之間傳。

小提示

  • iPad 沒聲音：關掉靜音模式、調高音量。
  • 用 Safari 的「分享 → 加入主畫面」，開啟時就是全螢幕。
  • 力道：滑得越快聲音越大；在靠近琴橋的位置彈聲音較亮，靠近琴頸較溫暖。
  • 敲琴身：面板中央較低沉（像大鼓），琴身外圍較清脆。
