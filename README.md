# 🎸 雙機吉他（Duo Guitar）

用**手機當左手**（按和弦 / 指板）、**iPad 當右手**（刷弦、發聲）的網頁吉他。
不用安裝 App，兩台都用瀏覽器打開就能玩。

| 裝置 | 頁面 | 功能 |
|---|---|---|
| iPad（右手） | `right.html` | 刷弦、撥單音、敲琴身、手掌悶音、切換樂器 / 調弦 / 移調夾、**聲音從這台出來** |
| 手機（左手） | `left.html` | 多指按格、橫按（封閉和弦）、滑音、搥勾弦、悶音；或「和弦模式」一鍵按和弦；或「🎮 音遊模式」當譜面顯示器 |

---

## 連線方式評估

| 方式 | 網頁可行？ | 說明 |
|---|---|---|
| 藍牙 | ❌ | iOS 上所有瀏覽器都**不支援 Web Bluetooth**；而且網頁只能當主控端（central），兩台瀏覽器無法互連。 |
| 有線 | ❌ | iOS 不支援 WebUSB / Web Serial，網頁拿不到 USB / Lightning 的資料通道。 |
| **網路（WebRTC）** | ✅ **採用** | 瀏覽器內建的 P2P DataChannel，iOS Safari 完整支援。同一個 Wi-Fi 下延遲約 5–20 ms。 |

做法：

1. iPad 開房，產生 4 位數房號（和 QR Code）。
2. 手機輸入房號或掃 QR Code。
3. 透過 [PeerJS](https://peerjs.com/) 的免費配對伺服器交換連線資訊（**只有配對時需要網路**）。
4. 配對完成後，按弦資料直接在兩台之間點對點傳送，不經過伺服器。

> 沒有 Wi-Fi？讓 iPad 連手機的「個人熱點」即可（熱點同時提供區網與配對需要的網路）。

## 怎麼玩

1. iPad 開 `right.html` → 點「開始」（開啟聲音）→ 左上角出現房號。
2. 手機用相機掃 iPad 上「📱 連手機」的 QR Code（或開首頁選「左手」輸入房號）。
3. 兩邊亮綠燈就連上了。手機橫放在 iPad 左邊，看起來就是一把吉他。

### 全螢幕、永遠橫向
- 手機和 iPad 都固定橫向：裝置直放時，畫面會自動轉 90° 變成橫的（iOS 網頁無法鎖定方向，所以用這個方式）。iPad 分割畫面時不會轉。
- **iPhone / iPad**：請用 Safari「分享 → 加入主畫面」，之後從主畫面的「左手指板」/「右手刷弦」圖示打開就是全螢幕（按 ⛶ 會顯示步驟）。
  不使用 Safari 的網頁全螢幕，因為在 iPad 上「往下刷弦」會被當成「離開全螢幕」的手勢。
- Android 等其他瀏覽器：開始時自動全螢幕，工具列 ⛶ 可以切換。

### 兩種擺放方式（iPad）
- **🪑 放桌上彈**：iPad 平放、自己看著彈（琴頸在左邊）。
- **🎤 演奏模式（面向觀眾）**：像一般吉他一樣把 iPad 抱在身上、螢幕朝外。畫面左右翻轉成觀眾看到的樣子（琴頸在右、粗弦在上），文字不翻轉；工具列收到左上角的小圓鈕（也會顯示連線燈號），點一下叫出來，開始彈就自動收起。
- 開始畫面直接選，之後可在 ⚙︎ 設定切換。**手機會跟著同步**：任一邊切換演奏模式，兩邊一起左右翻轉（手機指板琴頭在右）。手機的「左撇子模式」是給左手彈吉他的人，和演奏模式可以同時開。

### 右手（iPad）
- **上下滑過琴弦** = 刷弦（越快越大聲，往下刷 / 往上刷都可以）
- **點一下弦** = 單音
- **點琴弦以外的地方** = 敲琴身（面板中央低沉像大鼓，外圍 / 琴身外清脆）
- **按住琴橋右邊的區域** = 手掌悶音（Palm Mute）；一按下也會止住正在響的弦
- 靠近琴橋彈聲音較亮、靠近琴頸較溫暖
- 沒有手機也能玩：開「和弦列」點和弦再刷

### 左手（手機）
- **指板模式**：多指同時按；手指在同一格**往旁邊的弦拖** = 橫按；**左右滑** = 滑音；弦還在響時換格 = 搥弦 / 勾弦
- 左邊弦名點一下 = 該弦悶掉（✕）；右邊「悶音」長條按住 = 全部悶音
- ◀ ▶ 移動把位（顯示 1–24 格）
- ⚙︎ 設定 →「指板大小」（35%–100%）：指板從上往下等比縮小，底邊貼齊手機橫放時的下緣
- **和弦模式**：8 個和弦按鈕（可換預設組或自己編輯），旁邊有「悶音」按住鍵

### 🎮 音遊模式（手機）
- 手機變成**譜面顯示器**，和弦會**自動按好**，你只要在 iPad 上照著刷弦。
- 譜面有四種：**↓ 下刷**（粗弦→細弦）、**↑ 上刷**（細弦→粗弦）、**↕ 紫色長條**＝一直上下來回刷到長條結束（長度不限），空白＝休息。
- 三首歌：**小星星**（★，4/4）、**奇異恩典**（★★，3/4，有來回刷）、**卡農**（★★★，三輪由簡到難，結尾長長的來回刷）。
- 判定：PERFECT ±70ms、GOOD ±140ms、方向刷反＝「方向反了」；來回刷要刷夠次數。結束後顯示 S / A / B / C 評等，每首歌記錄最佳成績。
- 開始前有一小節預備拍；iPad 會播節拍器（可關）。覺得判定總是偏早 / 偏晚，可以調「判定校正」（±150ms）。網路延遲會自動扣掉。
- 需要先連上 iPad 才能開始；換到其他分頁會自動停止。

### 樂器
木吉他（鋼弦）、12 弦吉他、古典吉他（尼龍弦）、電吉他 Clean、電吉他 Crunch、電吉他重破音、電貝斯（4 弦）、烏克麗麗。
另有多種調弦（Drop D、降半音、Open G、Open D、DADGAD…）與移調夾 0–9。

## 部署（GitHub Pages）

整個專案是純靜態網頁，不需要後端。

1. GitHub repo → **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選放這些檔案的分支、資料夾選 `/ (root)` → Save
3. 約 1 分鐘後網址會出現在同一頁（`https://<帳號>.github.io/<repo>/`）
4. iPad 開 `…/right.html`，手機掃 QR 就好

> 必須用 **https**（GitHub Pages 預設就是）：iOS 的 AudioWorklet 與螢幕常亮都需要安全連線。
> 用 Safari「分享 → 加入主畫面」打開會是全螢幕。

### 本機測試 / 自架配對伺服器
所有頁面支援 `?ph=主機:埠/路徑` 參數，改用自己的 PeerJS Server（例如區網測試）：

```bash
npm i peer express
node -e "const e=require('express'),{ExpressPeerServer:P}=require('peer');const a=e();a.use(e.static('.'));const s=a.listen(8080);a.use('/peerjs',P(s,{path:'/'}))"
# 打開 http://localhost:8080/right.html?ph=localhost:8080/peerjs
```

## 技術架構

```
index.html        首頁（選角色、說明）
manifest-*.json   「加入主畫面」用：各自直接打開左手 / 右手頁面，全螢幕、橫向
right.html        右手 / iPad
left.html         左手 / 手機
js/music.js       音名、樂器參數、調弦、和弦指型表 + 自動找指型、和弦辨識
js/guitar-dsp.js  弦的物理模擬（擴充版 Karplus-Strong），在 AudioWorklet 裡跑；不支援時用 ScriptProcessor 備援
js/audio.js       音色鏈：木吉他琴身共鳴、古典、Clean 合唱、Crunch / 破音音箱、貝斯、殘響、敲琴身合成
js/net.js         WebRTC 連線（PeerJS）、自動重連、延遲量測、螢幕常亮、防誤觸縮放
js/right.js       iPad：畫吉他、刷弦偵測（跨弦判定 + 速度→力度 + 保留刷弦時間差）
js/left.js        手機：指板多點觸控、橫按 / 滑音、和弦按鈕與編輯
js/game.js        音遊模式：三首歌的譜面、判定（下刷 / 上刷 / 來回刷）、譜面繪製
vendor/           peerjs.min.js、qrcode.js（已內含，不依賴 CDN）
```

- 聲音全部即時合成，沒有音檔：每條弦是一條延遲線 + 阻尼濾波器，用分數延遲把音準校正到 0.1 cent 以內，換格時可以平滑滑音。
- 手機只傳「每條弦按在第幾格」（例：`[-1,3,2,0,1,0]`），資料量很小；iPad 會把每次撥弦回傳給手機，讓手機上的弦一起震動。

## 已知限制
- 第一次配對需要網路（PeerJS 免費伺服器）。兩台在不同網路（例如一台用行動網路）時可能連不上，建議同一個 Wi-Fi 或熱點。
- iPad 的**靜音模式**可能讓網頁沒聲音（iOS 17 以上會自動處理），請關掉靜音並調高音量。
- 需要 iOS / iPadOS 14.5 以上的 Safari（或其他瀏覽器）。
